A venue is a site with its own address, time zone and trading day. Locations are the places inside it that have their own tills, floor plans and printers: a bar, a restaurant, a terrace. Set them up before you go further, because floor plans, tills and menus all belong to a venue and its locations.

## Check your venues and locations

1. Go to **Settings**.
2. Under **Venues & locations**, select **Manage venues & locations**.

![Venues & locations in Settings](/docs/screenshots/getting-started/venues-and-locations.png)

Each venue shows its name, time zone, address and trading day start, with its locations underneath.

If you're an admin for only some venues, you see just those venues, and you can't add a new one. Ask an admin for the whole organisation to add it.

## Add a venue

You need to be an admin for the whole organisation.

1. On **Venues & locations**, select **Add venue**.
2. Enter a **Name**, and choose the venue's **Timezone**.
3. Optionally, enter an **Address**.
4. Check **Trading day starts at**. It starts at 05:00, which suits most venues.
5. Select **Create venue**.

Synapse creates a location called "Main" with the venue. Rename it or add more locations below.

## Edit a venue

1. On **Venues & locations**, change the venue's **Name**, **Timezone**, **Address (optional)** or **Trading day starts at**.
2. Select **Save**.

## Add or rename locations

Under the venue's **Locations**:

- To rename a location, change its name and select **Save** next to it.
- To add a location, type its name, such as "Terrace", and select **Add location**.

You can't delete or archive a venue or a location yet. If you need one removed, email support@gosynapse.net.

## Set when your trading day starts

The trading day decides which day a sale counts towards. With the default, 05:00, a sale at 01:30 counts towards the night before, so a late night's takings stay together.

1. On **Venues & locations**, change the venue's **Trading day starts at**.
2. Select **Save**.

Each venue has its own trading day, so set it for each one.

## If a page says a venue or location is missing

Pages that need a venue or a location, such as **Floor plans**, **Revenue centers** and **Bookings**, show a notice when there isn't one yet: **No venue set up yet** or **Your venues have no locations**.

- Select **Create a starter venue** or **Create a starter location** to make one in one click. A starter venue is called "Main venue", with a "Main" location; rename them on **Venues & locations** later.
- Or select **Or set up venues and locations yourself** to go to **Venues & locations**.
- Only admins see these two options. Anyone can select **Contact support**, which opens an email to us with the details filled in.

## Check your organisation's details

You need to be an admin for the whole organisation.

1. Go to **Settings** and select **Organisation details**.
2. Change the **Name** if you need to.
3. Check the **Country** and **Currency**.
4. Select **Save**.

Country and currency decide how money is shown and how VAT is worked out, so set them before you start trading. Once your organisation has taken money — a check, an invoice, a paid booking or room charge, or a house-account payment — they can't be changed here any more. If they're wrong after that, email support@gosynapse.net.
