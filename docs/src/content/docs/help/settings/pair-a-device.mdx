A new till or kitchen screen shows a short pairing code when it starts. Enter that code in the Synapse dashboard to connect the device to your organisation and tell it where it is.

## Before you start

Turn the device on and open the Synapse till or kitchen screen app. It shows a code like `K7M-4QX` and a QR code. The code changes every 10 minutes.

## Pair the device

1. Go to **Settings**, then **Devices**.
2. Select **Pair device**.
3. Enter the **Pairing code** shown on the device and select **Continue**.

   ![The Pair a device screen](/docs/screenshots/settings/pair-device.png)

4. Choose the **Venue** and **Location** the device is in.
5. Fill in what the device does:
   - For a till, choose its **Default revenue center**, or leave it to use the location's default.
   - For a kitchen screen, choose what it **Shows** (the whole pass, or one station such as Kitchen or Bar), and its **Mode**. In **Station** mode cooks bump the lines they make. **Expo** is the pass, which calls courses and sends plates.
6. Give it a **Name** staff will recognise, such as "Bar till 1" or "Grill".
7. Select **Pair device**.

Synapse confirms **Device paired**, and the device starts on its own within a few seconds.

## Manage paired devices

**Devices** lists every till and kitchen screen with where it is, what it does and whether it's online.

![The Devices list](/docs/screenshots/settings/devices.png)

- Select **Edit** to change where a device is, what it does or its name. Changes reach the device within a minute.
- Select **Revoke** to unpair a lost or replaced device. It stops working immediately and goes back to its pairing screen. Revoked devices are hidden; tick **Show revoked** to see them.
