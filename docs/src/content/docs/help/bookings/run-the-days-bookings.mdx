**Bookings** lists one day's bookings with their time, table, party size, member, status, source and spend.

1. Go to **Bookings**. It opens on today; pick another date if you need to.
2. To focus on what's still to come, set the status filter to **BOOKED**.

![A day's bookings](/docs/screenshots/bookings/day-view.png)

## As guests arrive

Select **Seat**. The booking shows **SEATED** and a check opens on the table, so the till can start the order. Its **Spend** column then shows what the table has spent.

## Cancellations and no-shows

- **Cancel** cancels a booked or seated booking.
- **No-show** marks a booking whose guests never arrived.

Both apply at once, with no confirmation, so check you've chosen the right row.

## Where bookings come from

The **Source** column shows where a booking was made: **INTERNAL** for bookings taken in Synapse, or the name of a connected booking system such as **SEVENROOMS**. Bookings from a connected system appear in this list too.
