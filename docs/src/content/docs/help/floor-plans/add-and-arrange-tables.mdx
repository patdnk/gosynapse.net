Tables belong to a seating area. Add an area first if you haven't: see [Set up floors and seating areas](/docs/help/floor-plans/set-up-floors-and-areas/).

## Add a table

1. Go to **Floor plans**, choose the location and stay in **Edit**.
2. Select **Add table**. To add straight into one area, select **+ table** next to that area instead.
3. Choose the **Seating area**.
4. Enter the **Table number** and **Seats**, and choose a **Shape**.
5. Select **Add table**.

![The Add table dialog](/docs/screenshots/floor-plans/add-table.png)

Table numbers must be unique across your whole organisation, not just this room.

## Arrange it

Drag the table to where it sits in the room. It snaps to the grid and saves as soon as you let go, so there's no save button for a move.

Select a table to open its settings next to the plan:

- **Number** and **Seats**, with quick buttons for common sizes.
- **Size** (small, medium or large) and **Shape**.
- **X (horizontal)** and **Y (vertical)**, or the arrow buttons, for exact placement.
- **Area**, to move it to another seating area.
- **Seat 1 sits at** and **Numbering runs**, so seat numbers on the till match the real table.

Select **Save table** after changing any of these.

![A table selected in the floor plan editor](/docs/screenshots/floor-plans/editor.png)

## Take a table out of service

- **De-activate table** keeps the table on the plan but stops it being used. **Re-activate table** brings it back.
- **Delete table** removes it for good, after you confirm.
