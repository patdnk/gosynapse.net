A floor plan shows the tables staff serve, laid out like the room. Each location has one or more floors, such as "Ground" or "Roof Terrace". Each floor has seating areas, such as "Window" or "Bar", and each area has tables.

1. Go to **Floor plans**.
2. Choose the location at the top, for example "Ashgrove House — Main Floor".
3. Make sure **Edit** is selected, not **Service (Live)**.

## Add a floor

1. Select **Add floor**.
2. Enter a **Name** and, if you like, the **Total area (m²)**.
3. Optionally choose a **Menu (optional)** for the whole floor.
4. Select **Create**.

To change a floor later, select it and choose **Edit floor**. That's also where you set the floor's **Revenue center**: see [Set up revenue centres](/docs/help/getting-started/revenue-centres/).

## Add a seating area

1. Select **Add area**.
2. Enter a **Name**, such as "Garden".
3. Choose its **Kind**: DINING, BAR, TERRACE, LOUNGE or PRIVATE.
4. If this area differs from the rest of the floor, choose a **Menu override (optional)** or a **Revenue center override (optional)**. Otherwise leave them to inherit from the floor.
5. Select **Create**.

![The Add area dialog](/docs/screenshots/floor-plans/add-area.png)

Each area appears above the plan with its number of tables. Select **edit** on an area to change or delete it.

## Use a background image

Select **Background image** to put a drawing of the room behind the plan. It makes placing tables easier, and staff recognise the room at a glance. **Remove bg** takes it away again.
