The live service view shows the room as it is right now: which tables are seated, which are booked next, and how each server is doing.

1. Go to **Floor plans** and choose the location.
2. Select **Service (Live)**.

![The live service view](/docs/screenshots/floor-plans/live-service.png)

## Read the room

- **Live service** at the side counts the tables seated, the covers and the bookings coming up.
- Each table is coloured as **Seated**, **Upcoming**, **Open** or **Out**. Seated tables show their covers and server's initials.
- Select a table to see who's there, the server, and the check number and total.
- **Servers** lists each server with their covers, tables and takings so far.

The view updates by itself as checks and bookings change, so you can leave it open on a screen during service. Tables can't be moved in this view; switch back to **Edit** to change the layout.
