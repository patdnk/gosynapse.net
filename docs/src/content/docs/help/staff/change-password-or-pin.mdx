There is no "forgot password" link in Synapse. When someone is locked out, an admin sets a new password for them. The same screen changes their role and their till PIN.

1. Go to **Staff**.
2. Find the person and select **Edit**.
3. Change what you need:
   - **Role**, to give them more or less access. See [Choose the right role](/docs/help/staff/roles-and-access/).
   - **Reset password (optional)**, at least 8 characters. Leave it blank to keep their current password.
   - **Set till PIN (optional)**, 4 to 6 digits, for unlocking the till.
4. Select **Save**.

![The Edit staff member dialog](/docs/screenshots/staff/edit.png)

To remove someone's till PIN without setting a new one, select **clear** next to **Set** in the **Till PIN** column.

## Good to know

- The email address can't be changed. If someone's email changes, add them again with the new address and remove the old entry.
- Changing someone's password or role signs them out everywhere, so they sign in again with the new details.
- Tell the person their new password yourself. Synapse doesn't send it to them.
