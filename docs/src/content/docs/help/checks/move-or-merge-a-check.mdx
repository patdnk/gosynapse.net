Guests change tables, servers change shifts and two parties decide to pay together. You can fix all of these on an open check from the Synapse dashboard. Every change is recorded in the check's **Movement trail**.

Open the check first: go to **Checks** and select it.

## Move to another table

1. Select **Move table**.
2. Choose the **New table**. The list comes from the location's floor plan.
3. Optionally add a **Reason (optional)**, such as "Guests asked to move inside".
4. Select **Move**.

![The Move check to another table dialog](/docs/screenshots/checks/move-table.png)

## Hand it to another server

1. Select **Transfer**.
2. Choose the **New server** and optionally a reason.
3. Select **Transfer**.

The header then shows the new **Server**.

## Move to another venue or room

1. Select **Move venue**.
2. Choose the **Destination** and optionally a reason.
3. Select **Move**.

The check moves with all its items and discounts and gets a new number at the destination. It isn't on a table there, so a till at the destination can pick it up, or a manager can transfer it to a server.

## Merge two checks

1. Open the check you want to keep and select **Merge**.
2. Choose the **Check to merge in** from the open checks at the same location, and optionally a reason.
3. Select **Merge**.

The other check's items move onto this one and the other check is voided.

## Good to know

- Only open checks can be moved, transferred or merged.
- A check that has had a card payment taken can't move venue or be merged. Finish paying it on the till instead.
- The header shows how many times a check has moved, and from which table.
