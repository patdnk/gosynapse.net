Guests come in two ways. A **member's guest** is signed in by the member who brings them. A **day pass** lets a non-member use the club for the day. Both get a pass code that can be checked in at the door.

## Add a walk-up guest on the FOH screen

When a member arrives with someone:

1. Open the member's page from the board.
2. Under **Add a walk-up guest**, enter the guest's **First name** and **Last name**, and select **Add**.
3. The guest appears under **Guests tonight** with a pass code. Select **Check in** to check them in; it changes to **✓ In**.

## Issue a pass in the Synapse dashboard

1. Go to **Reception** and find **Day & guest passes**.
2. Choose the **Type**: **Member's guest** or **Day pass**.
3. Enter the **Holder name**.
4. For a member's guest, search for the **Host member**.
5. Select **Issue pass**.

![Day & guest passes in Reception](/docs/screenshots/reception/issue-pass.png)

The pass appears in the list with its code, the date it's valid and its status. The holder checks in by giving that code at the door.

## Void a pass

Select **Void** next to an issued pass that shouldn't be used. Its status changes to **VOID** straight away, with no confirmation.
