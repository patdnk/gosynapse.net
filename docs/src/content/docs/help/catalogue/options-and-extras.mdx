An option set is a choice the till asks for when an item is ordered, such as which milk, which mixer or how a steak is cooked. Define the set once, then attach it to every item it applies to.

## Create an option set

1. Go to **Catalogue**, then the **Option sets** tab.
2. Select **Add option set**.
3. Enter a **Name**, such as "Milk".
4. Tick **Required** if staff must choose before the item can be added, and **Allow multiple** if guests can pick more than one.
5. Enter each option and its extra charge in **+£** ("0" if it's free). Select **Add option** for each one, such as "Whole milk" and "Oat milk" at +£0.50.
6. Select **Save set**.

![The Add option set dialog](/docs/screenshots/catalogue/option-set.png)

## Attach it to items

1. Select **Assign** next to the set.
2. Select **Add target**.
3. Choose **Category** to cover every item in a category, such as "Drinks", and optionally narrow it to one sub-category. Or choose **Item** to pick a single item.
4. Add more targets if you need them, then select **Save assignments**.

Every matching item now asks for the choice on the till, as well as any options set directly on the item.

## Good to know

For a choice that belongs to one item only, use **Options** next to that item on the **Menu items** tab instead.
