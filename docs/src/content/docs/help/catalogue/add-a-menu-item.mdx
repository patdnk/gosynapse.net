Adding something to sell takes two steps. First you create the **menu item**: what it is and how it's grouped. Then you put it on a **menu** with its price and VAT rate. Prices live on the menu, not the item, so the same dish can cost more on one venue's menu than another's.

## Create the menu item

1. Go to **Catalogue**, then the **Menu items** tab.
2. Select **Add menu item**.
3. Enter the **Name**, such as "Halloumi Fries", and a **Category**, such as "Sides".
4. Choose its **Sales group**. See [Group sales for reporting](/docs/help/catalogue/sales-groups/).
5. Optionally add a **Sub-category** and a **Description**.
6. Keep **Active** ticked.
7. Select **Save**.

![The Add menu item dialog](/docs/screenshots/catalogue/add-menu-item.png)

## Put it on a menu

1. Go to the **Menus** tab and choose the **Venue**.
2. Choose the menu, for example **All Day**.
3. Select **Add entry**.
4. Choose the **Menu item** and enter the **Price (£)**, including VAT.
5. Choose the **Tax rate**, and optionally the **Course** and **Station** it's sent to.
6. Select **Save**.

![The Add entry dialog](/docs/screenshots/catalogue/menu-entry.png)

The item now appears on that menu with its price, and the till can sell it.

## Good to know

- To change a price later, select **Edit** on the menu entry. **Remove** takes the item off this menu without deleting it.
- On **Menu items**, **Recipe** records the ingredients, and **Options** adds choices for this one item. For choices shared by many items, see [Offer options and extras](/docs/help/catalogue/options-and-extras/).
- Managers can see these pages but only admins can save menu items, menus, option sets and VAT rates.
