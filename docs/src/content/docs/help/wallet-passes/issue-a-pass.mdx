A member's pass is issued from their profile, and reaches them as a link they open on their phone.

1. Open the member's profile and find **Wallet passes**.
2. Choose the kind of pass: **Membership**, **Loyalty card** or **Day pass**.
3. Choose how to issue it:
   - **Link for any phone** makes one link that works on iPhone and Android. The pass is issued when the member opens it. The link expires in 7 days.
   - **Apple** or **Google** issues the pass straight away for that wallet.
4. For an issued pass, select **Send link**. It copies the link and the button changes to **Link copied**.
5. Paste the link into your own email, text or WhatsApp message to the member.

![An issued pass with Send link and Revoke](/docs/screenshots/wallet-passes/issued-pass.png)

## Good to know

Synapse doesn't send pass links automatically yet, so you send the link yourself. Every link is listed on the **Distribution** tab of **Wallet passes**, where you can copy or revoke it. See [Revoke a pass or link](/docs/help/wallet-passes/revoke-a-pass/).
