Revoke a pass when a phone is lost, a pass has been shared with someone who isn't a member, or a membership ends. You can also revoke a pass link that was sent to the wrong person before it's opened.

## Revoke a pass

1. Open the member's profile and find **Wallet passes**.
2. Select **Revoke** on the pass. It shows **REVOKED** straight away.

![An issued pass with its Revoke button](/docs/screenshots/wallet-passes/issued-pass.png)

## Revoke a link

A link that hasn't been opened yet can be revoked too:

1. Go to **Wallet passes**, then the **Distribution** tab.
2. Under **Recent links**, select **Revoke** next to the link. It shows **Revoked** instead of the date it's live until.

## Good to know

Neither action asks you to confirm, and neither can be undone. To give the member a working pass again, issue a new one. See [Give a member a wallet pass](/docs/help/wallet-passes/issue-a-pass/).
